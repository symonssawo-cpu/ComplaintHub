# ComplaintHub – Multi-Company Complaint Management System

A web application that lets customers submit complaints against registered 
companies. Companies can log in to a private dashboard to view complaints 
filed against them.

Built with HTML, CSS, JavaScript, PHP and MySQL as a university group 
assignment. No frameworks used.

## Pages
- `home.php` – Landing page
- `register.php` – Company registration
- `login.php` – Company login
- `submit_complaint.php` – Public complaint form
- `dashboard.php` – Company complaints dashboard
- `logout.php` – Logout

## Setup
1. Install XAMPP and start Apache + MySQL
2. Import `database.sql` via phpMyAdmin
3. Copy the project folder into `htdocs/ComplaintHub`
4. Open `http://localhost/ComplaintHub/home.php`
